# XeonKitPvP 2.1.0 build note

The project is Java 8 bytecode and targets Spigot API 1.8.8. Maven must be installed locally to resolve Spigot/ACF dependencies and produce the final shaded JAR.

Expected artifact:
`target/XeonKitPvP-2.1.0.jar`

The implementation was statically checked in this environment. A full Maven compile could not be executed here because Maven/dependency repositories are not available in the build environment.
